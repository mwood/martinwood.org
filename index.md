I'm a software engineer in Cardiff. I've been building for the web since 1997, mostly in Ruby on Rails, and these days mostly with AI.

Since 2015 I've built and run the technology behind [Photosymbols](https://www.photosymbols.com), a UK company that helps organisations make information easier to understand, with Easy Read and real photos of real people. It began as a photo library sold through a Shopify shop. Today it is an AI product: a council or health trust gives it a document and gets back an Easy Read version as a web page, an accessible PDF, a Word file, audio or video.

I work end to end – product thinking, architecture, test-driven Rails, Postgres, background jobs, deployment and keeping it all running – and I have been the platform's only developer since 2020.

## Selected work

**EasyMaker.** Turns a document or a web page into an Easy Read pack: web page, PDF, Word, audio, video and a share link, in 13 languages. A language model rewrites the text, and each point gets a matching photo, found in the library by semantic search or generated when nothing fits.

**Accessible PDFs.** Documents that meet PDF/UA, the accessibility standard for PDF. Headless Chromium makes the PDF, then a post-processing step adds what Chromium can't, checked with veraPDF and PAC.

**AI image provenance.** Invisible marking and signed C2PA Content Credentials on AI-generated images, built ahead of the EU AI Act's December 2026 deadline.

**An internal AI agent.** Dozens of read-only tools over the company's support, sales, project and photo data, which the team reaches from the web, by voice, from team chat, and from Claude over MCP.

**The Easy Read Standard checker.** A public tool at [easyreadstandard.org](https://easyreadstandard.org) that checks whether a document meets the Easy Read Standard.

**wt.** Tooling for running several AI coding agents on one Rails app at once, each in its own git worktree with its own database, port and status on a terminal dashboard.

**A personal AI assistant.** A Rails 8 app I use every day and treat as a lab: a tool-using chat agent, an MCP server, search over 56,000 saved bookmarks, and strict control of what each model call costs.
